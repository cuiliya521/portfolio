# CUI × 盘古｜真实产品驱动的动态构图 R0（隔离试验）

## 入口与保护
打开预览站根目录，URL 加 `?field-lab=1`；不带参数则沿用原 CUI 页面的逻辑和布局。
只改本实验分支 `experiment/cui-product-driven-field-r0`，不合并 main，不替换 production。

## 保留的内容
原首页、Workspace 三项目与路由、冻结 CUI 图片、原盘古 product-source.jpg、原盘古 R7 阅读镜头控制器、原来返回和小红书后续入口均不修改。没重画真实产品 UI，没生成新海报。

## 一次完整体验
1. 首页进入 Workspace，点「盘古智绘」。
2. 产品页直接使用原归档截图，桌面点击**原截图中画面风格那行**，手机点击同义的可触控入口。
3. 界面将原工作台置为主角；桌面同一张截图原位标出「画面风格：清爽明亮」及归档结果关系，CUI 让出空间；手机进入现有可读的字段区域镜头。
4. 点击「看归档海报」切换到现有的真实结果预览镜头；点击「重看全貌」撤销；随时可返回 Workspace，再进其他项目。

## 事实与实现边界
- 字段数值和青提柠檬海报来自提供的原始截图；点击**不生成**新图片，不改变归档素材。
- 用已有 `cui:pangu-evidence` 控制器切换镜头，并复用现有 demand 模型的 read-only evidence 状态；无第二套截图阅读器，不修改 A/B 原控制器。
- 新代码仅 `product-field-lab.css` 和 `product-field-lab.js`，首页只多了两个 opt-in 引用。
- 桌面字段热区按原图 1536×1024 坐标映射（画面风格 x398～831/y348～410）；位置动态跟踪原图真实边界。移动端不使用这个微小热区。
- 支持按钮键盘触发、44px 以上主要操作、reduced-motion 样式退化、返回原路；需要在真实浏览器进一步验收。

## 验收门槛
- 功能测试：1440×900、1366×768、390×844、360×780；首页到 Workspace 到盘古、字段聚焦、结果、撤销、返回、重新进入、窗口缩放、触控与键盘。
- 审美测试：原素材不能被模糊放大或重画；字段和海报可读、CUI 不遮挡按钮；不是又一种「截图阅读器＋注释卡」。
- 必须获得动态截图/录像后才能判为 GO；**Vercel READY 和源码静态检查不算动态验收。**

## 当前结论（未做真实浏览器可见性验收前）
TECH: 尚待浏览器验证。
AESTHETICS: HOLD / 未签 GO。
