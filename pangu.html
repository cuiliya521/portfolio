CASE 01 / 盘古智绘 · 企业 AIGC 产品运营河北盘古网络 / 2024.12—2025.08

把「写 Prompt」
变成「选字段」。

本地中小商户不会写专业 Prompt，需求表达依赖反复沟通。我的判断：将复杂需求结构化，让商户通过选择完成输入。

支撑判断的工作证据
15+ / 200+

商户深访 / 问卷

9 / 230+ / 2500+

行业 / 场景标签 / Prompt

3 轮

A/B 测试

01 / 产品判断

降低输入门槛，
从理解商户的表达方式开始。

商户有明确的营销需求，却不一定能把它写成专业提示词。继续依赖自由输入，会把产品使用门槛留给用户。

因此，将行业、场景、主题、风格、构图和平台规格拆成可选择的字段；用标签与 Prompt 体系承接这些选择，并让生成结果进入预览、管理与复用流程。

我的工作：用户调研、需求与流程梳理、标签及 Prompt 语料建设、A/B 测试，并协同多团队推进 MVP 落地。
02 / 后续业务结果

6h → 1.2h
