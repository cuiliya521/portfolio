## 工程层级（由后往前）
1. 单独背景层：Workspace 同源背景轻推进版。
2. 单独角色层：锁定 CUI 透明 PNG，**不可重绘**。
3. 软件窗口层：盘古主窗最大；小红书右上 1 大 2 小；NoteGuard 右下；冀芽成长轻量文件夹。
4. HTML 文字与按钮层：所有标题、描述、CTA、交互均可选中/点击，不放在整页扁平图片里。
5. 独立 Dock：工作台、我的能力、关于我、联系我，单独下载简历入口；保证与「冀芽成长」横条有留白，不可互相贴住或裁掉。

## 文案与数据真实性
- 小红书不要新增未核实的曝光、留资、ROI、增长百分比等。
- NoteGuard 标准路线：风险识别→建议→人工决策→采用后复检；不要用静态示意图假装实时执行成功。
- 盘古主窗口的目标是展示真实或明示脱敏重构的产品 UI，不能用生成器补造不存在的按钮和指标。
- 用户还在另一个对话独立设计 CUI 语音交互，本包**不擅自新增说话交互或替换话术**。
